# Background Bash

## 1. 行为规则

如果命令进程退出后的自动进程组清理返回 `EPERM`，系统应保持当前 pi 会话运行且不发送额外清理错误消息。

## 2. 对外接口

- 命令执行：用户执行会自然退出的命令后，可继续在同一 pi 会话发起下一项操作。
- 自动清理错误：`EPERM` 不产生额外会话消息。

## 3. 验收例子

### 自动清理权限不足时会话保持可用

- 触发: 操作 在自动进程组清理固定返回 `EPERM` 的运行环境中执行一个会自然退出的命令，随后继续执行下一项操作
- Given: pi 会话已启动，后台命令能力已启用，且运行环境会让命令退出后的自动进程组清理返回 `EPERM`
- When: 用户执行一个会自然退出的命令并等待其退出，然后在同一会话发起下一项操作
- Then: pi 进程保持运行，下一项操作可被正常接收，且会话中没有新增自动清理错误消息
